# Política de Privacidad --- MarínBunny Bot

## 1. Datos que Se Recopilan

-   IDs de usuario, servidor y canal.
-   Mensajes necesarios para ejecutar comandos.
-   Logs básicos para depuración.

## 2. Cómo Se Usan

-   Para ejecutar funciones del bot.
-   Para mejorar estabilidad, detectar errores y evitar abuso.

## 3. Retención de Datos

Los datos se conservan solo el tiempo necesario para operar el bot. No
se almacenan datos sensibles.

## 4. Seguridad

Intentamos mantener los datos seguros. Aun así, recuerda que nada en
internet es 100% invulnerable.

## 5. Terceros

No compartimos datos con terceros. Cero filtraciones, cero ventas, cero
drama.

## 6. Cambios en la Política

Podemos actualizar esta política cuando sea necesario. Si continúas
usando el bot, aceptas las nuevas condiciones.

## 7. Contacto

Si tienes preguntas, contacta al soporte del bot.
