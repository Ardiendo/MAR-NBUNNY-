## 📦 Instalación

``` bash
git clone https://github.com/tu-usuario/MarinBunny.git
cd MarinBunny
npm install   # o pip install -r requirements.txt si usas Python
```

------------------------------------------------------------------------

## ⚙️ Configuración

1.  Entra a **Discord Developer Portal**\
2.  Crea tu bot\
3.  Copia tu **TOKEN**\
4.  Guárdalo en `.env`:

``` env
DISCORD_TOKEN=tu_token_legendario
```

5.  Luego ejecuta:

``` bash
npm start
# o python main.py
```
